# Dev Mode v1.1.0 Release Notes

**Release Date:** October 15, 2026  
**Version:** 1.1.0 (Version Code: 2)  
**Package:** `com.devmode.app` / `com.devmode.app.dev`  

Dev Mode v1.1.0 introduces **App Shield & Auto-Off protection**, brand-new **1x1 & 3x1 Launcher Widgets**, a dedicated **Home Screen Widgets Studio**, and a completely overhauled **Cyber Emerald Green** design for developer quick toggles.

---

### What's New in v1.1.0

#### 1. App Shield (Auto-Off Protection)
- **Instant Anti-Tamper Bypass:** Automatically disables Developer Options, USB Debugging, and Wireless Debugging the millisecond a protected app (such as GCash, Maya, ShopeePay, or banking apps) is launched.
- **Automatic State Restoration:** Seamlessly turns your Developer Options back ON when you return to your desktop launcher or switch back to your coding and developer tools.
- **100% Offline & Private:** Zero cloud telemetry, zero remote tracking, and zero network calls. All process monitoring runs strictly on-device.

#### 2. Home Screen Widgets (1x1 & 3x1)
- **1x1 Single App Quick Launch Widget:**
  - Place a dedicated 1x1 home screen button for any shielded app (e.g., GCash or Maya).
  - Tapping the widget automatically disarms Developer Options and ADB before launching the app for a guaranteed, warning-free launch.
- **3x1 Multi-App Shield Dock:**
  - A sleek horizontal desktop dock that houses your top 3 protected apps in a single row.
  - One-tap launch with instant Auto-Off armed status.
- **One-Tap Home Screen Pinning:**
  - Direct launcher pinning support for Android 8.0+ (Pixel Launcher, Samsung One UI, Nova Launcher, and more).

#### 3. Home Screen Widgets Studio (`/widget-settings`)
- **Interactive Widget Format Selector:**
  - Effortlessly choose between **1x1 App**, **3x1 Dock**, and **Dev Mode Toggles**.
  - High-visibility style cards with generous spacing, icons, and active emerald glow.
- **Interactive App Picker & Live Previews:**
  - Choose which shielded app to pin for 1x1 widgets.
  - Realistic on-screen mockups reflecting the actual Android widget layouts and status.

#### 4. Developer Quick Toggles Redesign
- **100% Cyber Emerald Green Theme:**
  - Switched Dev Toggles to full emerald green (`#15803D`, `#4ADE80`, `#08140F`), matching the native widget XML styling and overall app branding.
- **Authentic Native Layouts:**
  - 3x1 Multi-Toggle widget preview faithfully recreates `dev_toggle_widget.xml` (DEV MODE, USB ADB, WIRELESS).
  - 1x1 Single Toggle previews faithfully recreate `dev_toggle_single_dev_widget.xml`.

#### 5. Navigation & UI Polish
- **Direct Widget Shortcuts in App Shield:**
  - Added a dedicated `[ Widgets ]` button directly beside `[ + Add App ]` in the App Shield header, empty state, and bottom actions row.
- **Clean Secondary Stack Screens:**
  - Removed persistent bottom navigation from the Home Screen Widgets screen for a clean, distraction-free view.
- **Clean App Cards:**
  - Streamlined App Shield rows to maximize readability and performance.

### Architecture & Requirements

- **Minimum Android Version:** Android 7.0 (Nougat, API 24)
- **Target Android Version:** Android 15 (API 35)
- **Supported ABIs:** `arm64-v8a` (64-bit modern devices), `armeabi-v7a` (32-bit legacy devices)
- **Permissions:**
  - `WRITE_SECURE_SETTINGS` (Required for toggling Developer Options rootless via ADB or Dev Mode CLI)
  - `PACKAGE_USAGE_STATS` (Optional: for background App Shield detection)
  - `POST_NOTIFICATIONS` (Optional: for background status notification)
  - `INSTALL_SHORTCUT` (For pinning widgets and shortcuts)

### Installation & One-Time Setup

1. Install the APK for your architecture:
   - **`app-arm64-v8a-release.apk`**: Standard for modern 64-bit devices (~35 MB).
   - **`app-armeabi-v7a-release.apk`**: For older 32-bit devices (~29 MB).
2. Connect your device to your computer via USB debugging once and grant secure settings:
   ```bash
   # Option A: Dev Mode CLI
   npm install -g dev-mode-cli
   devmode grant

   # Option B: Plain ADB
   adb shell pm grant com.devmode.app android.permission.WRITE_SECURE_SETTINGS
   ```
