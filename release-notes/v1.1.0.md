# Dev Mode v1.1.0 Release Notes

**Release Date:** October 15, 2026  
**Version:** 1.1.0 (Version Code: 2)  
**Package:** `com.devmode.app` / `com.devmode.app.dev`  

Dev Mode v1.1.0 is a massive update introducing **Multi-Language Support (20 Languages)**, **Shizuku Integration** for computerless setup, **App Shield & Auto-Off Protection** for banking apps, brand-new **1x1 & 3x1 Desktop Launcher Widgets**, a dedicated **Home Screen Widgets Studio**, **APK Size Optimizations**, and a refreshed **Cyber Emerald Green** design.

### What's New in v1.1.0

#### 1. Shizuku Integration (Computerless On-Device Setup)
- **No PC Required:** Grant privileges and toggle developer settings directly on your Android phone using Shizuku!
- **Wireless Debugging Bridge:** Connect Dev Mode to Shizuku on-device via Wireless Debugging—no USB cables or computer commands required.
- **In-App Shizuku Authorization:** Dedicated Shizuku controls inside **Security & Privacy (`/security-settings`)** and onboarding with one-tap permission request.
- **Live Status Badges:** Real-time feedback showing whether Shizuku is `AUTHORIZED`, `PROMPT` (needs permission), or `OFFLINE`.
- **Seamless Fallback:** Full backwards compatibility with traditional ADB and Dev Mode CLI (`WRITE_SECURE_SETTINGS`).

#### 2. Multi-Language Support (20 Languages & On-Device Translation)

#### 3. App Shield (Auto-Off Protection)
- **Instant Anti-Tamper Bypass:** Automatically sets Developer Options, USB Debugging, and Wireless Debugging to **OFF** the millisecond a protected app (such as GCash, Maya, ShopeePay, banking apps, or anti-tamper games) starts up.
- **Automatic State Restoration:** Seamlessly re-enables your Developer Options back ON when you return to your home screen or switch back to your coding and developer tools.
- **100% Offline & Private:** Zero cloud tracking, zero analytics, zero data leaves your device. Process monitoring runs strictly on-device using local system calls.

#### 4. Home Screen Widgets (1x1 & 3x1)
- **1x1 Single App Quick Launch Widget:**
  - Place a dedicated 1x1 home screen widget for any shielded app (e.g., GCash, Maya).
  - Tapping the widget automatically disarms Developer Options and ADB before launching the app for guaranteed, warning-free access.
- **3x1 Multi-App Shield Dock:**
  - A sleek horizontal desktop dock that houses your top 3 protected apps in a single row with "⚡ AUTO-OFF ARMED" status.
- **One-Tap Home Screen Pinning:**
  - Direct launcher pinning support for Android 8.0+ (Pixel Launcher, Samsung One UI, Nova Launcher, and more).

#### 5. Home Screen Widgets Studio (`/widget-settings`)
- **Interactive Widget Format Selector:**
  - Effortlessly choose between **1x1 App**, **3x1 Dock**, and **Dev Mode Toggles**.
  - Spacious, elevated style cards with generous padding, icons, and active emerald glow.
- **Interactive App Picker & Live Previews:**
  - Choose which shielded app to pin for 1x1 widgets with live desktop mockups.
  - Authentic previews reflecting actual Android widget layouts, states, and colors.

#### 6. Developer Quick Toggles Redesign
- **100% Cyber Emerald Green Theme:**
  - Converted Dev Toggles to full emerald green (`#15803D`, `#4ADE80`, `#08140F`), matching native widget XML styling and overall app branding.
- **Authentic Native Layouts:**
  - 3x1 Multi-Toggle widget preview faithfully recreates `dev_toggle_widget.xml` (DEV MODE, USB ADB, WIRELESS).
  - 1x1 Single Toggle previews faithfully recreate `dev_toggle_single_dev_widget.xml`.

#### 7. APK Size Optimization & Build Polish
- **Native Library Compression:** Enabled `expo.useLegacyPackaging=true` alongside R8 code shrinking and resource removal, compressing native C++ `.so` libraries to reduce the APK download footprint down to **~32–35 MB** (saving ~15 MB).
- **Direct Widget Shortcuts in App Shield:** Added a dedicated `[ Widgets ]` button directly beside `[ + Add App ]` across all headers and empty states.
- **Clean Secondary Stack Screens:** Removed persistent bottom navigation from the Home Screen Widgets screen for a clean, distraction-free experience.

### Architecture & Requirements

- **Minimum Android Version:** Android 7.0 (Nougat, API 24)
- **Target Android Version:** Android 15 (API 35)
- **Supported ABIs:** `arm64-v8a` (64-bit modern devices), `armeabi-v7a` (32-bit legacy devices)
- **Permissions:**
  - `WRITE_SECURE_SETTINGS` (Required for toggling Developer Options rootless via ADB, Dev Mode CLI, or Shizuku)
  - `PACKAGE_USAGE_STATS` (Optional: for background App Shield detection)
  - `POST_NOTIFICATIONS` (Optional: for background status notification)
  - `INSTALL_SHORTCUT` (For pinning widgets and shortcuts to the home screen)

### Installation & Setup

1. Install the APK for your phone architecture:
   - **`app-arm64-v8a-release.apk`**: Standard for almost every modern phone (~32–35 MB).
   - **`app-armeabi-v7a-release.apk`**: For older 32-bit phones (~28 MB).

2. Choose your preferred authorization method:

   #### Method A: On-Device via Shizuku (No PC / No Cable Required 🚀)
   1. Install and start [Shizuku](https://shizuku.rikka.app/) on your device (via Wireless Debugging).
   2. Open Dev Mode and tap **"Authorize in Shizuku"**.
   3. Ready to toggle Developer Options immediately!

   #### Method B: Dev Mode CLI (via PC)
   ```bash
   npm install -g dev-mode-cli
   devmode grant
   ```

   #### Method C: Plain ADB (via PC)
   ```bash
   adb shell pm grant com.devmode.app android.permission.WRITE_SECURE_SETTINGS
   ```
