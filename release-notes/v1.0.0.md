## Dev Mode v1.0.0 (test release)

Rootless Android utility to toggle Developer Options, USB Debugging and Wireless Debugging in one tap, with home screen widgets and a notification shade bar. 100% offline, no account, no telemetry.

### Features

**Core debugging**
- One-tap **Developer Options**, **USB Debugging** and **Wireless Debugging** toggles
- Live **IP:port** display for Wireless Debugging with one-tap copy
- **Keep Wireless On**: Android turns Wireless Debugging off whenever Wi-Fi drops; Dev Mode turns it back on when Wi-Fi returns (can be switched off in Developer Settings)

**Performance and system tools**
- **Speed Booster**: window, transition and animator scales to 0.5x in one tap
- Custom animation scales: Off, 0.25x, 0.5x, 1.0x, 1.5x
- Stay awake while charging, show touches, pointer location overlay
- **Instant Cleanup**: resets scales and overlays in one tap

**Home screen and notification**
- 3x1 multi-control widget, plus 1x1 widgets for Developer Options, USB Debugging and Wireless ADB
- Persistent notification shade bar with quick toggle chips
- Widgets and notification stay in sync when you change settings from your PC

**Dev Mode CLI companion**
- Grant the permission and control the app from your computer: `devmode grant`, `devmode auto`, `devmode wifi on`

### Install

1. Download the APK for your phone:
   - **`app-arm64-v8a-release.apk`**: almost every modern phone (about 35 MB)
   - **`app-armeabi-v7a-release.apk`**: older 32-bit phones only (about 29 MB)
2. Open it and allow **Install unknown apps** when Android asks.
3. Open Dev Mode and follow the onboarding.

Requires Android 7.0 or newer.

### One-time permission setup

Dev Mode needs `WRITE_SECURE_SETTINGS`, which only a computer can grant. Connect your phone with USB debugging on, then pick one:

```bash
# Dev Mode CLI (needs Node.js and adb)
npm install -g dev-mode-cli
devmode grant

# or without installing
npx dev-mode-cli grant

# or plain ADB
adb shell pm grant com.devmode.app android.permission.WRITE_SECURE_SETTINGS
```

Use `npx dev-mode-cli`, not `npx devmode` (that is a different npm package).

### Control Dev Mode from your PC with `devmode`

After `npm install -g dev-mode-cli`, the `devmode` command is available in any terminal. Install name is `dev-mode-cli`, the command you run is `devmode`.

```bash
devmode auto          # one-key menu: press a letter to run a command
devmode grant         # grant the permission to the app
devmode on            # Developer Options ON       (devmode off to turn it off)
devmode usb on        # USB Debugging ON           (devmode usb off)
devmode wifi on       # Wireless Debugging ON and auto-connect over Wi-Fi
devmode wifi off      # Wireless Debugging OFF and disconnect
devmode status        # show device status and the current Wi-Fi IP:port
devmode help          # all commands
```

Run `devmode auto` for the easiest start. The CLI also works over Wi-Fi through the app, so you can toggle settings without a cable once the app is running. Widgets and the notification update right away when you change settings from your PC.
